# 走查示例 · 山海间旅拍

这一套示例，是灵小兔用「山海间旅拍」（三亚婚纱旅拍店）从零跑完八道工序的真实产出。

**作用有两个：**

1. **给商家看的**：先看一遍，就知道灵小兔最后会给你什么——不是聊天记录，而是 8 份能直接拿去开拍的 Markdown 文件。
2. **给想二改的人看的**：这是一份可参照的输出格式范本，8 份文件的 frontmatter、正文结构、字段取值都对齐了 `references/` 里的规范。

## 文件链路

```
商家档案.md   ──你是谁──▶  客群画像.md   ──客户是谁──▶  账号定位.md
     ▲                                                    │
     │                                                  发什么
     │                                                    ▼
拍摄方案.md ◀──怎么执行── 分镜表.md ◀──怎么拍── 脚本.md ◀── 选题清单.md ◀─ 内容矩阵.md
```

上游文件喂下游文件，每一步都不重新问已经聊过的事。

## 怎么自己跑一遍

1. 新建一个空目录（当作你的店）。
2. 对灵小兔说：`帮我给一家三亚的海景民宿起个号、做一批选题、写第一条脚本`。
3. 顺着流水线走，你会得到和本目录同结构的 8 份文件（文件名、frontmatter、正文结构一致，内容换成你的店）。

> 提示：示例里的时间戳（14:00 → 15:10）是同一轮演示里按工序顺序推进的，实际使用时以你当天的真实时间为准。
