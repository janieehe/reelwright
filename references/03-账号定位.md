# 工序 3 · 账号定位

## 定位

帮商家把生意优势翻译成抖音、小红书、视频号三平台清晰可执行的账号人设与定位方案。产出沉淀为长期档案 `账号定位.md`，供内容矩阵等后续工序复用。

## 目标

产出 2-3 个人设方向，用户选定后微调，最终沉淀为三平台 × 六项内容的完整定位方案。

## 上游

读 `商家档案.md`（商家档案）+ `客群画像.md`（客群画像）。定位贴合档案中的真实业务、客单价与目标客群；档案信息与用户当前说法冲突时，先与用户确认再采用。档案缺失时：提示「建议先完成『商家档案』与『客群画像』，账号定位会更贴合实际」，随即基于已知信息直接开始。

## 执行流程

### 步骤 1 · 生成方向

产出 2-3 个人设方向，方向之间在「人设内核」上有实质差异（如专业顾问型、亲切同伴型、审美向导型），差异落在角色内核而非仅昵称或文案。每个方向覆盖抖音、小红书、视频号三平台，每平台给出六项内容。

**六项内容**：

| 内容 | 要求 |
|------|------|
| 角色定位 | 一句话说清「我是谁」，落在具体业务与人群上 |
| 昵称建议 | 1-2 个备选；贴合人设、简短易记、无生僻字 |
| 简介 | 一句话说清「我是谁、对谁、提供什么价值」，在平台字数上限内 |
| 内容标签 | 3-6 个；兼顾搜索词与人群词 |
| 目标人群 | 与客群画像对齐，落到可识别人群 |
| 风格调性 | 形容词加具象描述，避免空泛 |

**平台差异**（同一方向在三平台差异化表达，不共用同一套文案）：

| 平台 | 生态特点 | 定位侧重 |
|------|---------|---------|
| 抖音 | 算法分发、强娱乐性、完播率驱动 | 强化人设记忆点与开场钩子，节奏快、情绪足 |
| 小红书 | 图文种草、搜索属性强、女性用户为主 | 强化专业感与干货价值，标题贴近搜索词 |
| 视频号 | 微信生态、社交裂变、信任关系强 | 强化真实感与信任背书，偏私域承接与转化 |

### 步骤 2 · 选定方向

说明各方向适配的商家形态与取舍，请用户选定。用户未明确表态时，追问一次「哪个方向更贴近你？都不满意的话，我换个角度再出方向」。

### 步骤 3 · 微调

围绕选定方向，逐项响应用户的修改请求（如只改某平台昵称或简介），只动被点名的项，其余保持不变。用户反复纠结某项时，给出一版稳妥默认值并说明理由，请用户确认或否决。

### 步骤 4 · 终稿与归档

按序输出三平台完整终稿 → 收尾语「账号定位已建立 ✓ 后续『内容矩阵』会基于它继续，想调整随时说」。用户认可后写入 `账号定位.md`。

## 表述规则

- 营销表述用可验证措辞，主动规避「最好/第一/全网独家」等绝对化用语，给合规替代写法
- 平台规则与数据只陈述可确证的内容，无法确证时如实说明

## 完成标准

终稿三平台 × 六项完整，用户认可后写入档案，收尾语已输出。

## 边界

- 只提供内容营销建议；医疗、法律、金融、税务等执业判断，建议咨询专业人士
- 不给涨粉、流量、销量做确定性承诺；改为可验证的运营动作与衡量指标
